How It Works

  1. Upload a PDF — the system extracts text from every page.
  2. Text is split into overlapping chunks (1 000 chars, 150 overlap).
  3. Each chunk is embedded using all-MiniLM-L6-v2 and stored in Astra DB.
  4. When you ask a question, the top-4 most relevant chunks are retrieved by vector similarity.
  5. Retrieved chunks are passed as context to Groq (openai/gpt-oss-120b) along with your question.
  6. The answer is generated strictly from the document — no outside knowledge is used.
